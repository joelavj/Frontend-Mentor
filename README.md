## Structure du dépôt

Un dossier par défi, nommé avec le même identifiant que sur Frontend Mentor (en minuscules, mots séparés par des tirets) :

```text
.
├── README.md
├── faq-accordion/
│   ├── assets/
│   ├── design/
│   ├── index.html
│   ├── style.css
│   ├── index.js
│   └── README.md
└── nom-du-prochain-defi/
    └── ...
```

## Lancer un projet

Les projets sont écrits en HTML, CSS et JavaScript, sans outil de build ni dépendance à installer.

1. Clone le dépôt :

   ```bash
   https://github.com/joelavj/Frontend-Mentor.git
   ```

2. Ouvre le dossier du défi voulu dans ton éditeur.
3. Lance `index.html` avec l'extension **Live Server** de VS Code, ou ouvre simplement le fichier dans ton navigateur.

## Compétences travaillées

- Intégration fidèle d'une maquette (espacements, typographie, couleurs)
- Mise en page avec Flexbox et media queries pour s'adapter aux écrans
- JavaScript vanilla pour les interactions (manipulation du DOM, événements)
- Accessibilité : HTML sémantique, navigation au clavier, états de focus, attributs ARIA
- Lecture de la documentation (MDN, WAI-ARIA) et débogage avec les outils du navigateur

## Ajouter un nouveau défi

1. Crée un dossier à la racine avec l'identifiant du défi (par exemple `nom-du-defi`).
2. Copie-y les fichiers de départ fournis par Frontend Mentor et réalise le projet.
3. Remplace le `README.md` du défi par une version personnalisée (technologies utilisées, ce que j'ai appris, pistes d'amélioration).
4. Ajoute une ligne dans le tableau [Défis réalisés](#défis-réalisés) ci-dessus.
